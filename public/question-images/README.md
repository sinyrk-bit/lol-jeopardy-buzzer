# Question Images

Put your own question and answer images in this folder.

Use them in `src/data/questions.ts` like this:

```ts
{
  id: 'champions-100',
  category: 'Champions',
  value: 100,
  question: 'Welcher Champion ist das?',
  answer: 'Lee Sin',
  questionImage: 'question-images/lee-sin-question.png',
  answerImage: 'question-images/lee-sin-answer.png',
}
```

Supported browser formats include `.png`, `.jpg`, `.jpeg`, `.webp`, and `.svg`.
